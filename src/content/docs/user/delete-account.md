---
title: Delete Your Account
description: How to delete your account in the BeaComm app
---

BeaComm is a self-hosted instant messaging application. Any account you sign in to through the BeaComm app belongs to a BeaComm chat server backed by the BeaComm server software operated by that server's owner.

Deleting your account therefore removes only the account registered on that specific BeaComm server. Sign in to that server first, then proceed with the deletion.

If you have already joined a BeaComm server and want to delete your account, follow these steps:

1. Sign in to the BeaComm app.
2. Go to **Settings > Privacy & Security**.
3. Select **Delete My Account**.
4. Select **Get Verification Code**.
5. Retrieve the verification code from your registered email address.
6. Enter the code in the BeaComm app to complete the deletion.
