---

BeaComm（Beacon + Communication）是一款轻量、开箱即用的私有化聊天服务器软件，单条命令即可完成部署并投入使用。

## 部署服务器软件包

登录服务器，打开终端，执行以下命令：

```shell
/bin/bash -c "$(curl -fsSL https://www.example.com/BeaComm/install.sh)"
```

## 获取服务器接入地址

安装完成后，终端将输出用于客户端登录的服务器接入地址，格式如下：

```
http://123.123.123.123:2443
```

## 获取客户端

前往官网首页的“[下载客户端](/zh-cn/#download)”栏目，获取对应平台的手机 App 或桌面客户端。

## 登录服务器

1. 启动客户端，在“服务器地址”中填入上一步获取的接入地址。
2. 输入邮箱与密码，完成注册或登录。
