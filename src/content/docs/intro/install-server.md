title: Installation
description: Deploy a BeaComm server and sign in with a client in minutes.
---

BeaComm (Beacon + Communication) is a lightweight, self-hosted chat server that works out of the box — a single command is all it takes to get up and running.

## Install the server package

Open a terminal on your server and run:

```shell
/bin/bash -c "$(curl -fsSL https://www.example.com/BeaComm/install.sh)"
```

## Get your server address

When the installation finishes, the terminal prints the address clients use to connect:

```
http://123.123.123.123:2443
```

## Get the client apps

Download the mobile or desktop client for your platform from the “[Download](/#download)” section on the home page.

## Sign in

1. Launch the client and enter the server address from the previous step in the **Server address** field.
2. Sign in with your email address and password, or create a new account.
