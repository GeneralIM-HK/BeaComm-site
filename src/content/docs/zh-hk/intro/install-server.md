BeaComm（Beacon + Communication）是一款輕量、開箱即用的私有化聊天伺服器軟件，單一指令即可完成部署並投入使用。

## 部署伺服器軟件包

登入伺服器，開啟終端機，執行以下指令：

```shell
/bin/bash -c "$(curl -fsSL https://www.example.com/BeaComm/install.sh)"
```

## 取得伺服器接入地址

安裝完成後，終端機將輸出供用戶端登入的伺服器接入地址，格式如下：

```
http://123.123.123.123:2443
```

## 取得用戶端

前往官網首頁的「[下載用戶端](/zh-hk/#download)」區塊，取得對應平台的手機 App 或桌面用戶端。

## 登入伺服器

1. 啟動用戶端，在「伺服器地址」填入上一步取得的接入地址。
2. 輸入電郵與密碼，完成註冊或登入。
