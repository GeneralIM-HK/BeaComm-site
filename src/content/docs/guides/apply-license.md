---
title: Apply a License
description: Activate a purchased license key from the admin console.
---

1. Purchase a Commercial or Enterprise license on the home page to receive your license key.
2. In the BeaComm admin console, open the License management page.
3. Paste the license key and click **Apply** — the new license takes effect immediately.
4. Once activated, the Server information page in the admin console shows the updated expiration date and seat limit.
